# Photo Levelup 動画台本

プロジェクト「Photo Levelup（AI写真コーチング）」の紹介動画用台本案です。スライド形式のプレゼンテーション動画を想定しています。

| スライド番号 | 画面・映像のイメージ (Visual) | セリフ・テロップ (Script) |
| :--- | :--- | :--- |
| **01** | **タイトルスライド**<br>中央にロゴ「Photo Levelup」。<br>サブタイトル：「AI写真コーチング - Go, Next.js, GenAI ADK」 | 写真をプロ級に「レベルアップ」させるAIコーチングアプリ、「Photo Levelup」について紹介します。 |
| **02** | **コンセプト**<br>左に「元の写真」、右に「お手本（改善後）の写真」。<br>スライダーでBefore/Afterを比較するアニメーション。 | あなたの撮った写真、もっと良くするには？<br>このアプリは写真を分析し、採点。さらにAIが「理想的な一枚」を生成して提案します。 |
| **03** | **デモ：分析とスコアリング**<br>ブラウザ画面。<br>画像アップロード → レーダーチャート（構図、露出、色彩など8項目）が表示され、総合スコアが出る。 | インターフェースは親しみやすいチャット形式。<br>画像をアップロードすると、AIコーチが構図やライティングを即座に分析し、8項目のレーダーチャートで採点します。 |
| **04** | **技術スタック**<br>アイコン：Next.js, Firebase, Go, Cloud Run, Firestore, GenAI ADK | 技術スタックはGoogle Cloudを活用。<br>フロントはNext.js (Firebase)、バックエンドはGo (Cloud Run) という構成です。 |
| **05** | **アーキテクチャ：ハイブリッド**<br>全体図。<br>Goサーバー（ADK Runner）とGenAIの連携を強調。 | 単なるチャットボットではありません。<br>Goによる画像処理ロジックと、GenAIの対話能力を組み合わせた「ハイブリッドアーキテクチャ」が特徴です。 |
| **06** | **アーキテクチャ：コンテキスト注入**<br>フロー図：画像 → Go解析 → 履歴(Session State)へ注入 → 会話開始 | 画像をアップロードすると、まずGoが解析。<br>その結果をAIの「記憶（セッションステート）」にシステム側から注入することで、AIは最初から画像の詳細を知った状態で的確なアドバイスができます。 |
| **07** | **GenAI ADK**<br>GenAI ADKのロゴやコードイメージ（Go）。 | これを実現するのが「Google GenAI App Development Kit (ADK)」。<br>複雑になりがちなマルチターンの会話履歴やステート管理を、フレームワークが強力にサポートします。 |
| **08** | **機能：Gemini 3 Pro Image**<br>「お手本を見せて」と入力 → 高品質な画像が生成される。<br>「Nano Banana Pro」のロゴなど。 | さらに、最新の画像生成モデル「Gemini 3 Pro Image」を活用。<br>分析結果に基づき、構図や色味を改善した「お手本」画像を生成し、視覚的に改善点を教えます。 |
| **09** | **まとめ**<br>・サーバーレス (Cloud Run)<br>・ハイブリッドAI (Go + ADK)<br>・実践的UX (コーチング) | サーバーレスの拡張性と、ADKによる柔軟なエージェント開発。<br>Photo Levelupは、AIによる新しい写真学習体験を提供します。 |
